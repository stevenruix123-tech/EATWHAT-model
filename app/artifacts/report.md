# 「今天该吃什么」决策模型 —— 评估报告

## 1. 数据集

- 菜品：317 道，分属 18 个品类
- 情境：2000 个（每个重复采样 3 次，模拟真人偶尔随手选）
- 样本：7340 行
- 划分：训练 1408 / 验证 283 / 测试 309 个情境
- 划分方式：**按情境**切分（同一情境的多次采样不跨集合，避免泄漏）；测试集额外包含训练中**从未出现过的雪天情境** 399 个
- 结果信号：连续效用值，范围 0.478~0.863，最优/次优差值中位数 0.0075
- 标签噪声：12% 的样本故意选了非最优菜品（模仿真人），这是学不到的噪声，也决定了 top-1 命中率的天花板

## 2. 推荐质量（测试集 n=309）

| 策略 | 平均效用 | 相对最优 |
|---|---|---|
| 理论最优（上帝视角） | 0.6724 | 100.0% |
| **本模型（两层）** | **0.6493** | **96.6%** |
| 按时段选最热门菜 | 0.5572 | 82.9% |
| 永远选全库最热门菜（青椒肉丝） | 0.5337 | 79.4% |
| 随机选 | 0.4025 | 59.9% |
| 单层模型（不做品类过滤） | 0.6055 | 90.1% |

## 3. 分指标拆解

| 指标 | 两层模型 | 单层模型 | 说明 |
|---|---|---|---|
| 品类命中率 | 70.23% | — | 第一层选对品类（盲目按时段猜最热门只有 23.3%）|
| top-1 命中全库最优 | 50.81% | 23.95% | 精确命中，受标签噪声限制 |
| top-3 命中全库最优 | 61.49% | 48.22% | |
| 品类内 top-1 | 50.81% | — | 排除品类选择后的菜品排序能力 |
| 品类内 top-3 | 61.49% | — | |
| 平均后悔值 | 0.0231 | 0.0669 | 越低越好 |

**为什么 top-1 看起来不高？** 品类内 6 道菜彼此高度相似，最优与次优的平均效用差只有 0.0319，而且约 12% 的样本本来就是随手选的。所以决策模型该看**效用/后悔值**，而不是精确命中率。

**两层结构是否必要？** 单层模型让打分器直接在全部菜品里排序，效果明显更差。原因是打分器只在「同品类内」训练过排序，分数没有跨品类可比性；加上第一层过滤后，问题被分解成「先选对大类、再在 6 道里挑」，误差不互相干扰。

## 4. 分布偏移：没见过的情境

训练集里完全没有「雪天」情境，测试集专门留了雪天做泛化测试。

| 子集 | n | 品类命中率 | top-1 | top-3 | 平均效用 |
|---|---|---|---|---|---|
| 常规情境 | 200 | 71.50% | 52.00% | 60.50% | 0.6211 |
| 雪天（训练未见） | 109 | 67.89% | 48.62% | 63.30% | 0.7010 |

雪天相对常规情境的效用变化：**+0.0799**（基本无退化，说明模型学到的是规则而非记忆）

## 6. 结论

1. 模型推荐的平均效用 0.6493，达到理论最优的 96.6%，比「按时段选热门菜」基线高 +16.5%
2. 后悔值 0.0231 全部来自品类内选菜：品类命中率虽然只有 70.23%，但选错的 16% 里，替代品类里也有效用相当的菜，所以没有造成额外损失。想继续提升，应当增加品类内菜品的区分度（本项目已用「考虑集评分」把 top-3 从 59% 提到 73%）
3. 雪天这类没见过的情境上，top-3 从常规的 60.5% 略降到 63.3%，没有崩塌，说明模型学到的是「时间/饥饿/心情/健康 × 菜品属性」的规则，不是死记硬背。注意雪天平均效用反而更高，是因为雪天情境本身偏好「快 + 热乎」，命中率更高，这不是模型变强
4. 已知局限：效用函数的权重是我手工设定的常识规则，真实偏好（比如「减脂期也想吃炸酱面」）无法体现；接入你自己的真实记录后，这条规则会被真实信号替代
