# 「今天该吃什么」决策模型 —— 评估报告

## 1. 数据集

- 菜品：824 道，分属 19 个品类
- 情境：20000 个（每个重复采样 3 次，模拟真人偶尔随手选）
- 样本：74242 行
- 划分：训练 15780 / 验证 2820 / 测试 1400 个情境
- 划分方式：**按情境**切分（同一情境的多次采样不跨集合，避免泄漏）；测试集额外包含训练中**从未出现过的雪天情境** 4462 个
- 结果信号：连续效用值，范围 0.469~0.863，最优/次优差值中位数 0.0060
- 标签噪声：12% 的样本故意选了非最优菜品（模仿真人），这是学不到的噪声，也决定了 top-1 命中率的天花板

## 2. 推荐质量（测试集 n=1400）

| 策略 | 平均效用 | 相对最优 |
|---|---|---|
| 理论最优（上帝视角） | 0.7114 | 100.0% |
| **本模型（单阶段·整目录 softmax）** | **0.7044** | **99.0%** |
| 按时段选最热门菜 | 0.6344 | 89.2% |
| 永远选全库最热门菜（卤水豆腐） | 0.6153 | 86.5% |
| 随机选 | 0.4129 | 58.0% |

## 3. 分指标拆解

| 指标 | 数值 | 说明 |
|---|---|---|
| 品类命中率 | 69.64% | 选中那道菜所属品类是否等于最优秀所属品类（盲目按时段猜最热门只有 15.1%）|
| top-1 命中全库最优 | 53.29% | 精确命中，受标签噪声限制 |
| top-3 命中全库最优 | 78.93% | |
| 平均后悔值 | 0.0071 | 越低越好 |

**为什么 top-1 没有更高？** 全库 824 道菜里，最优与次优的平均效用差只有 0.0052，而且约 12% 的样本本来就是随手选的。所以决策模型该看**效用/后悔值**，而不是精确命中率。

**为什么是单阶段？** 打分器用「整目录 824 路 softmax」训练（交接文档 §7.4），分数天生跨品类可比，所以不需要先过滤品类 —— 这也修掉了「薄品类候选太少，第 2/3 名只能从该品类内挑」的问题。

## 4. 分布偏移：没见过的情境

训练集里完全没有「雪天」情境，测试集专门留了雪天做泛化测试。

| 子集 | n | 品类命中率 | top-1 | top-3 | 平均效用 |
|---|---|---|---|---|---|
| 常规情境 | 200 | 79.00% | 69.00% | 89.00% | 0.6316 |
| 雪天（训练未见） | 1200 | 68.08% | 50.67% | 77.25% | 0.7165 |

雪天相对常规情境的效用变化：**+0.0849**（基本无退化，说明模型学到的是规则而非记忆）

## 6. 结论

1. 模型推荐的平均效用 0.7044，达到理论最优的 99.0%，比「按时段选热门菜」基线高 +11.0%
2. 后悔值 0.0071 全部来自品类内选菜：品类命中率虽然只有 69.64%，但选错的 30% 里，替代品类里也有效用相当的菜，所以没有造成额外损失。想继续提升，应当增加品类内菜品的区分度（可用「考虑集评分」给同品类的非最优菜补观测信号）
3. 雪天这类没见过的情境上，top-3 从常规的 89.0% 降到 77.2%，但远高于随机水平，说明模型学到的是「时间/饥饿/心情/健康 × 菜品属性」的规则，不是死记硬背。注意雪天平均效用反而更高，是因为雪天情境本身偏好「快 + 热乎」，命中率更高，这不是模型变强
4. 已知局限：效用函数的权重是我手工设定的常识规则，真实偏好（比如「减脂期也想吃炸酱面」）无法体现；接入你自己的真实记录后，这条规则会被真实信号替代
